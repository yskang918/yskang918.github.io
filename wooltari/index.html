우리 반만 쓰는 학급 담벼락, 울타리

울타리는 선생님이 자기 구글 계정에 직접 설치해 사용하는 학급 담벼락입니다. 학생 글과 사진은 선생님 계정의 저장소에만 보관되며, 제작자는 이를 볼 수 없습니다.

설치 프로그램 내려받기개인정보 처리방침

주요 기능

담벼락학생이 글·사진·링크·파일을 올리고 좋아요와 댓글을 남깁니다.
모둠별 게시판모둠 탭으로 나누어 글을 모으고, 선생님이 순서를 정리합니다.
선생님 관리글 확인 후 공개, 댓글·좋아요 사용 여부, 담벼락 잠금을 설정합니다.

설치 방법

  1. 설치 프로그램을 내려받아 실행합니다.
  2. 울타리를 사용할 구글 계정으로 로그인하고 권한을 허용합니다.
  3. 화면 오른쪽 안내 창에 따라 구글 클라우드·Firebase 약관에 동의하고 구글 로그인을 사용 설정합니다.
  4. 설치가 완료되면 선생님 계정에 만들어진 울타리 주소(wooltari-○○○○○○.web.app)가 열립니다.

울타리는 Firebase 무료 요금제(Spark)로 설치되며, 결제 카드를 등록하지 않습니다.

구글 계정 권한을 요청하는 이유

설치 프로그램은 선생님 계정에 울타리용 프로젝트를 만들고 설정하기 위해 아래 권한을 요청합니다. 이 권한은 설치와 업데이트에만 사용하며, 선생님의 메일·드라이브·다른 프로젝트 자료에는 접근하지 않습니다.

이메일 주소
openid email		설치한 계정을 울타리의 선생님 계정으로 지정합니다.
Google Cloud 관리
cloud-platform		울타리용 프로젝트를 만들고, 필요한 기능(저장소·로그인·보안 규칙)을 켭니다.
Firebase 관리
firebase		Firebase를 연결하고 울타리 화면을 선생님의 주소에 올립니다.

업데이트

새 버전이 나오면 선생님 화면에만 알림이 표시됩니다. [업데이트]를 누르면 선생님 PC의 울타리 도우미가 새 화면을 선생님 프로젝트에 올립니다. 업데이트 정보는 공개 저장소(GitHub)의 버전 파일에서 확인합니다.

의견 보내기

선생님 화면의 [의견 보내기]로 오류 신고와 기능 요청을 보낼 수 있습니다. 선생님이 직접 보내기를 누를 때만 전송되며, 사용 기록과 화면 캡처는 선생님이 선택한 경우에만 함께 보냅니다.

About Wooltari (English)

Wooltari is a class bulletin board that each teacher installs into their own Google account. The installer asks for Google Cloud and Firebase access only to create and configure a Firebase project owned by the teacher (Firestore, Authentication, Hosting) and to deploy app updates to that project. All class data stays in the teacher's own project. The developer runs no server and receives no user data. See the privacy policy.
